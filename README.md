# Data Cleaning and Preprocessing

## Data Analyst Internship – Task 1

This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python and Pandas.

### Dataset
Netflix Movies and TV Shows dataset.

### Data Cleaning Performed
- Handled missing values in relevant columns.
- Checked and removed duplicate records.
- Standardized text values and removed unnecessary whitespace.
- Converted `date_added` to a consistent datetime format.
- Checked and verified data types.
- Checked the final data quality.
- Saved the cleaned dataset as netflix_cleaned.csv.

### Files
- `data_cleaning.ipynb` – Python/Pandas data cleaning notebook.
- `netflix_titles.csv` – Original dataset.
- `netflix_cleaned.csv` – Cleaned dataset.

### Summary
The dataset was inspected, cleaned, and validated by handling missing values, checking duplicates, standardizing text, converting date formats, and verifying data types.
